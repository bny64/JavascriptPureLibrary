# UI 및 뷰 전환 기본 검증
1. `http://localhost:3000` 에 접속하여 초기 화면(캘린더)이 오류 없이 로드되는지 확인한다.
2. 사이드바의 5개 주요 메뉴(대시보드, 캘린더, 간트 차트, 칸반 보드, 활동 로그)를 순차적으로 클릭하여 화면이 정상 전환되는지 확인한다.
3. 브라우저 개발자 도구의 콘솔(Console) 영역에 UI 렌더링 관련 JavaScript 에러가 없는지 모니터링한다.

# 1. 📈 대시보드 (Dashboard) 뷰 테스트
1. "전체 업무", "대기 업무", "진행 중", "완료 업무" 요약 카드가 올바른 숫자를 표시하는지 확인한다.
2. 요약 카드 클릭 시: 해당 상태값(예: '진행중')을 필터 조건으로 가진 "전체 업무 목록" 팝업 모달창이 열리는지 검증한다.
3. 상태별 차트 및 우선순위 차트 바 클릭 시: 해당 상태나 우선순위로 필터링된 팝업 모달창이 연결되어 열리는지 확인한다.
4. 카테고리별 진행률 막대가 정상적으로 계산되어 표시되는지 확인한다.
5. 카테고리를 선택했을 때 필터 조건으로 팝업 모달창이 열리는지 확인한다.

# 2. 📅 캘린더 (Calendar) 뷰 테스트
1. 상단 현재 연/월 텍스트(`YYYY년 M월`)가 정상적으로 출력되는지 확인한다.
2. [이전 달], [다음 달] 버튼을 클릭해 달력 그리드가 정상적으로 다시 그려지는지 검증한다.
3. 달력 셀에 업무 마커(점이 있는 형태)가 상태 색상에 맞게 표시되는지 확인한다.
4. 특정 날짜 달력 셀을 클릭 시, 하단 목록 제목이 `선택한 날짜의 업무` 로 바뀌고 해당 날짜의 테스크 리스트가 렌더링되는지 확인한다.
5. 하단 목록 영역의 필터 버튼(전체, 대기, 진행중, 완료 등)을 눌렀을 때 해당 날짜의 업무 목록이 정상 필터링되는지 검증한다.
6. 전체 업무 팝업 열어서 모든 필터기능이 정상적으로 동작되는지 확인한다

# 3. 📊 간트 차트 (Gantt Chart) 뷰 테스트
1. 업무 시작일(`startDate`)과 종료일(`endDate`)이 존재하는 항목들만 차트에 렌더링되는지 확인한다.
2. 상단 필터(상태별 필터, 우선순위별 필터) 버튼 클릭 시: 
   - 선택된 버튼이 활성화(Active) 상태로 변경되는지 확인.
   - 간트 차트 리스트가 해당 조건에 맞게 즉시 재렌더링되는지 확인.
3. 차트 바를 드래그 앤 드롭으로 날짜 이동 시 업무의 날짜 데이터가 정상적으로 업데이트되는지(API 호출 및 갱신) 검증한다.
4. 좌측 라벨 섹션 상하 스크롤과 우측 차트 바 섹션 상하 스크롤이 동기화되는지 시각적으로 체크한다.

# 4. 📋 칸반 보드 (Kanban Board) 뷰 테스트
1. '대기', '진행중', '완료', '보류' 4개 컬럼 영역과 상단에 각 항목들의 총 개수가 올바르게 렌더링되는지 확인한다.
2. 컬럼별 개별 검색(Search Input): 특정 키워드를 입력 시 해당 컬럼 내의 업무들만 제목 및 설명 내용 기준으로 실시간 필터링(렌더링)되는지 확인한다.
3. 드래그 앤 드롭: 
   - '대기' 상태 카드 하나를 드래그하여 '진행중' 컬럼으로 이동(Drop)시킨다.
   - 드롭 즉시 API 통신 오류가 발생하지 않고, 카드의 상태 카테고리가 시각적으로 이동 및 갱신되는지 확인한다.

# 5. 📜 활동 로그 (Activity Log) 및 전역 모달 테스트
1. 활동 로그 화면에서 상단의 [새 업무 추가], [상태 변경], [업무 삭제] 등의 필터 버튼을 클릭 시 로그 리스트가 알맞게 필터링되는지 확인한다.
2. 5개의 어떤 뷰 화면이든, 우측 상단의 "전역 검색 바(Global Search)"에 키워드 입력 시 10개까지의 연관 검색 결과가 드롭다운으로 뜨는지 확인한다.
3. 모달 테스트:
   - 전역 검색 결과 클릭 시 해당 업무의 상세 보기 모달이 열리는지 검증한다.
   - 간트, 칸반 등의 업무 카드 클릭 시에도 상세 업무 모달창이 정상적으로 열리는지 검증한다.
